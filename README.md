# Topic Quiz Creator

Type in any topic and get a five-question multiple-choice quiz generated by an LLM. You take it in the browser and it's graded on the server, with per-question feedback.

**Stack:** Next.js 14 (App Router, API routes) · TypeScript · Vercel AI SDK · OpenAI GPT-4o-mini · MongoDB · shadcn/ui · Tailwind CSS · Framer Motion

---

## How it works

```
Topic ─▶ GET /api/generate ─▶ ai-service: prompt the LLM for strict JSON
                                │   ├─ extract and parse JSON from the reply
                                │   ├─ validate the shape (5 questions × 4 options)
                                │   └─ on any failure → curated fallback quiz
                                ▼
                    MongoDB: questions (public) + correctAnswers (server-only)
                                │
Client gets questions only ◀────┘
Answers ─▶ POST /api/grade ─▶ compare against stored answers ─▶ score + feedback, result saved
```

## Design decisions

- **Answers never reach the client.** The generate endpoint returns only questions and options. Correct answers are stored with the quiz in MongoDB and read only by the grading route, so nobody can find them in the network tab.
- **Treat LLM output as untrusted.** The AI service pulls the JSON block out of the model's reply, parses it and checks its structure before anything is saved. A malformed reply never turns into a broken quiz.
- **Graceful degradation.** If the API key is missing, the model call fails or the output doesn't validate, the route switches to a curated fallback quiz, and the response's `generatedBy` field (`"AI"` or `"fallback"`) shows which one was used. The app keeps working when OpenAI is down.
- **Results stored for later.** Every graded attempt is saved, so the results page and any future analytics read from one source.

## API

**`GET /api/generate?topic=<topic>`**

```json
{
  "quizId": "abc123",
  "questions": [{ "id": 1, "text": "What is React?", "options": ["A JavaScript library", "A database", "A server", "An OS"] }],
  "generatedBy": "AI"
}
```

**`POST /api/grade?quizId=<quizId>`**, body `{ "answers": { "1": "A JavaScript library" } }`

```json
{ "correct": 4, "total": 5, "feedback": [{ "id": 1, "yourAnswer": "A JavaScript library", "correctAnswer": "A JavaScript library" }] }
```

## Getting started

```bash
npm install
cat > .env.local <<EOF
MONGODB_URI=mongodb+srv://<user>:<pass>@<cluster>/quiz_app
OPENAI_API_KEY=sk-...
EOF
npm run dev
```

It runs without `OPENAI_API_KEY` too, using the fallback quizzes.

## Project structure

```
app/
  api/generate/route.ts   Generate + persist a quiz
  api/grade/route.ts      Grade against stored answers
  quiz/[quizId]/          Take a quiz
  results/[quizId]/       Score and per-question feedback
lib/
  ai-service.ts           Prompting, JSON extraction, validation, fallback
  quiz-service.ts         Quiz and result persistence
  mongodb.ts              Pooled client
```
